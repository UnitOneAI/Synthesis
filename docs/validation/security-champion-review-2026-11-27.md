# Security champion improvements — qualification record

Candidate: static-pilot 0.12.1. Static-only changes to Synthesis; no JCI source,
target application, target tests or deployment controls were executed.

## Product changes

* New decisions bind reviewer questions to typed, scoped conditions. Consequences
  are generated by the product and do not approve unrelated routes or boundaries.
* Code-dependent conditions reuse a cited code obligation. Invalid references,
  missing bindings, redacted evidence and unresolved consistency cannot establish
  a supported decision. A model consistency statement is not semantic proof.
* Critical review explicitly tests whether reversing a prerequisite would change
  the current attack path. It narrows unsupported impact and separates current
  behavior from hypothetical future code and unproven isolation requirements.
* A one-case recheck is explicit, metered and bounded to four requests. The old
  assessment is archived. Ordinary resume and report exports retain paid results.
* Reports/UI show actor-to-operation evidence and separate operation review,
  settled threats, ruled-out paths, investigations and six-category completion.
  A current version-2 conclusion supersedes the original speculative display
  title; the original discovery record and technical title remain available.
* Guide profiles retain source/version/references and declared repository scope.
  They do not establish runtime access. The example JCI profile is based on the
  supplied guide, not observation of an installation.

## Real saved open-autofix case

Used the existing SQLite graph read-only and hash-checked source windows. Rechecked
one existing gap-read scenario; did not run new discovery or rebuild the graph.
Provider: direct Anthropic `claude-opus-4-6`, not the JCI gateway.

Contract qualification encountered five HTTP 400 attempts with no token usage
reported. Diagnostic responses identified the native structured-output grammar
size limit. These attempts are **unknown usage**, not assumed free. The final wire
format groups assessment fields, derives endpoints from the validated trace, and
reuses obligation citations for conditions rather than compiling duplicate nested
citation objects. CWE's wire contract is unchanged. Native structured output
remains enabled; no silent provider/mode fallback was introduced.

The first accepted native response took 92 seconds and reported 28,777 tokens.
It still retained an irrelevant authentication flag condition. That response was
rejected during engineering qualification despite its own `consistent` label.
This is direct evidence that structure checks and a model self-review do not
establish semantic correctness.

After strengthening the counterfactual condition check, the next one-call review
took 88 seconds and reported 29,194 tokens. It returned a supported conditional
unauthenticated gap-data disclosure case, with three explicit conditions:

1. The caller can reach the relevant API path.
2. An upstream gateway does not authenticate that path.
3. The intended data policy restricts gap data from unauthenticated callers.

The unused authentication flag was removed as a prerequisite. The consistency
record explains that toggling it does not attach authentication to these routes.
The current conclusion narrows the impact to data disclosure; it does not claim
write/execution or an established per-user isolation violation. Effective exposure
and data policy still require reviewer declarations. The source register and graph
fingerprint were unchanged. One other returned scenario remains unassessed; the
larger discovery scope remains 1/506 packets. This is not whole-repository or JCI
completion.

Across this qualification: **57,971 reported tokens in two accepted provider
responses**, plus **five requests with unknown usage**. This includes the response
rejected for semantic quality. It excludes prior release qualification; it is not
an equal-scope speedup or portfolio cost forecast. The 88-second figure is only
the final recheck, not total development or investigation time.

The rendered PDF and HTML are local validation artifacts outside the source
repository. Export replays make no model calls and preserve saved assessments.
